# مغامرات الرياضيات (الصف الثالث الأساسي)

موقع ثابت بالعربية (RTL) بلا أي مكتبات أو خطوة بناء. افتح `index.html` مباشرة، أو شغّل `python3 -m http.server` من هذا المجلد.

## البنية
- `index.html`: هيكل الصفحة (ترويسة، `<main id="content">`، تذييل) وتحميل الملفات.
- `css/styles.css`: الأنماط. القسم الأخير بعنوان «إعادة التصميم: دفتر مغامرات» هو طبقة التصميم الجديدة فوق الأنماط الأصلية.
- `js/app.js`: التطبيق الأصلي: التوجيه بالـ hash (`#home`, `#worlds`, `#world/geometry`, `#lesson/geometry/0/<stage>`)، وأنشطة درس «الشعاع والمستقيم»، وتخزين التقدم في localStorage.
- `js/audio-layer.js`: طبقة الصوت. تعيد تعريف `stopAudio` و`readArabic` و`message` و`render`، وتغلّف دوال المعالجة (`handleApplication` و`handleFormative` و`handleNaming` و`handleDrawing` و`finishDrawing` و`beginDrawing` و`updatePoints` و`rotateRay` و`completeHandStep`) لتشغيل المقطع المناسب وعرض نصه. دالة `screen()` تحدد مقاطع كل شاشة.
- `js/clips.js`: جدول المقاطع (`window.CLIPS`): اسم الملف -> المتحدث والنص. يُحمَّل قبل `audio-layer.js`.
- `audio/`: ١٢٨ ملف MP3، الاسم = مفتاح المقطع (مثل `l01-06-apply-ray-correct.mp3`).
- `assets/images/`: صور WebP للشخصيات والمشاهد (img-01 إلى img-20). `assets/fonts/`: Noto Kufi وNoto Naskh مع الترخيص.
- `docs/audio-scripts.docx`: دليل الصوتيات (النصوص ومواضع التشغيل). `docs/clips.json`: النسخة الآلية منه.
- `original/`: الملف الأصلي المرسَل (ملف واحد بكل شيء مضمّن) للمقارنة.

## قواعد تشغيل الصوت (من الدليل)
- سؤال الشاشة يُشغَّل عند طلب الاستماع (زر الشريط السفلي أو أزرار `.chip`).
- التغذية الراجعة تُشغَّل عند «تحقّق»، والتلميح عند «أعطني تلميحًا»، إذا كان زر «الصوت» مفعّلًا.
- يتوقف الصوت عند تغيير الشاشة. النص يبقى ظاهرًا، وحروف النقاط تُكتب رموزًا (أ، ب، ج، د، م).

## ملاحظات معروفة
- مقاطع ناقصة في الحزمة المرسَلة (تُعرض نصوصها دون صوت حتى تُضاف): `l01-04-explain-fix-segment`, `l01-07-name-ray-hint`, `l01-08-quiz-draw-ray-correct`.
- مقاطع `l02-*` (الزاوية وأنواعها) غير مربوطة لأن شاشات الدرس غير مبنية بعد. بقية المحطات تعرض قالب «قيد الإعداد».
- المنطق يعتمد على نصوص رسائل `app.js` الأصلية (مثل `startsWith("اختر اسم الشكل أولًا")`) لتصنيف نتيجة التحقق. عند تعديل تلك النصوص عدّل التصنيف في `audio-layer.js`.
