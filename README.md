# مغامرات الرياضيات: اكتشف، جرّب، وتحدَّ!

منصة تعلّم رقمية تفاعلية لطلبة **الصف الثالث الأساسي**، مستندة إلى كتاب الرياضيات الفلسطيني للصف الثالث الأساسي – الجزء الأول. تحوّل المحتوى الرياضي إلى رحلة استكشافية بالرسوم والشخصيات والمختبرات والألعاب والتقويم بتغذية راجعة فورية.

> مشروع أكاديمي ضمن مساق **تصميم المحتوى الرقمي**، برنامج الماجستير – كلية التربية – الجامعة الإسلامية بغزة.

## الفئة المستهدفة
طلبة الصف الثالث الأساسي (ومعلموهم).

## الأساس التربوي
نموذج التصميم التعليمي **ADDIE**، ومبادئ ماير للتعلّم بالوسائط المتعددة، ومبادئ **التصميم الشامل للتعلّم (UDL)**. لكل درس أهداف قابلة للقياس مرتبطة بنشاط وأداة تقويم.

## الشخصيات
المعلمة رنا (المرشدة)، والطفل المستكشف، والطفلة المستكشفة، والطائر الأزرق المساعد.

## طريقة التشغيل
المشروع ملف واحد مكتفٍ بذاته. لا يحتاج تثبيتًا ولا خادمًا:
1. نزّل المستودع أو الملف `index.html`.
2. افتحه بأي متصفح حديث (يعمل على الحاسوب والهاتف).

الخط العربي (Cairo) يُحمَّل من Google Fonts عند توفر الإنترنت، وله خط بديل، فيعمل المشروع بدونه.

## إمكانية الوصول
واجهة عربية RTL، تصميم متجاوب، دعم اللمس والفأرة ولوحة المفاتيح، نصوص بديلة للرسوم، وزر «تقليل الحركة» مع احترام إعداد النظام `prefers-reduced-motion`.

## الخصوصية
- لا حسابات ولا تسجيل دخول.
- يُحفظ تقدّم المتعلم على جهازه فقط (`localStorage`) ولا يُرسل إلى أي خادم.
- لا يتضمن المشروع مفاتيح API أو رموز وصول أو بيانات شخصية.
- التسجيلات الصوتية غير متوفرة بعد؛ زر الاستماع يستخدم صوت المتصفح العربي إن وُجد.
